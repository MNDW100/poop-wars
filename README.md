# 푸프 워즈 (Poop Wars)

[푸프 워즈](https://mndw100.github.io/poop-wars/)

버전 2.0입니다. 브라우저에서 바로 플레이할 수 있는 단일 HTML 게임으로 별도 빌드나 외부 라이브러리가 필요하지 않습니다.

## GitHub Pages 공개

1. GitHub에서 `poop-wars`라는 **Public** 저장소를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 루트에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
4. 배포가 끝나면 `https://<GitHub 사용자명>.github.io/poop-wars/`에서 플레이할 수 있습니다.

## 로컬 실행

`index.html`을 최신 브라우저에서 열면 됩니다.
